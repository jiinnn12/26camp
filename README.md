# 🎓 Upstage AI 기반 대입 진학 시뮬레이터

2022 개정 교육과정(5등급제) 내신 성적을 정밀 환산하고, **Upstage Solar AI**를 통해 목표 대학 진학 맞춤형 컨설팅 리포트를 제공하는 스트림릿(Streamlit) 웹 애플리케이션입니다.

---

## ✨ 주요 기능

- 📊 **소수점 내신 정밀 환산:** 5등급제 성적을 입력받아 기존 9등급제 추정 등급 및 백분율 산출
- 🎯 **신분별 맞춤형 진학 리포트:** 고등학교 재학생 / 자퇴생(검정고시) 맞춤형 입시 가이드 제공
- 🤖 **Upstage Solar AI 연동:** 목표 대학 합격선 분석 및 성적 격차 극복 실질 전략 제시

---

## 🛠️ 사용 기술 (Tech Stack)

- **Frontend / Web:** Python, Streamlit
- **AI Model:** Upstage Solar API (`solar-pro`)
- **Deployment:** Streamlit Community Cloud
- **Version Control:** GitHub

---

## 🚀 서비스 이용 방법

1. [앱 링크 접속](https://your-app-name.streamlit.app)
2. 좌측 사이드바에서 **학생 신분**, **5등급제 성적**, **목표 대학/학과** 입력
3. **[Upstage AI 맞춤형 진학 리포트 생성하기]** 버튼 클릭!
